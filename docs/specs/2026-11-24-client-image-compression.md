# Turbo 图片压缩、缓存与使用记录

2026-11-24。此文描述客户端和平台的联动；部署及灰度启用独立进行。

## 客户端

运行偏好里的**压缩模式**是本地出站压缩的总开关，控制图片编码、HTTP zstd 和私有 WebSocket 帧的 zstd，WS 的连接开关仍独立。关掉压缩后，私有协议仍可使用**未压缩帧**；接收端始终可解码对端的帧。保留已有用户的总开关值。点旁边的齿轮能在不切换总开关的情况下编辑本机设置。

压缩方式只显示“无损 / 有损”，默认无损、单图阈值 **0 KB**，不设整批触发门槛。只采用真正比原图小的结果，不显示“交给平台”选项。无损不改尺寸；有损可选自动/JPEG/PNG、最长边（默认 2048 px）和 JPEG 质量（默认 85）。“最小图片大小”按 New API 的 B / KB / MB（1 KB = 1000 B）输入，保存为整数字节，重开优先显示能用整数表示的最大单位，零显示为 0 KB；有损时超过最长边也可触发。透明、方向、色彩与多帧含义不能保证时保留原图。只处理 Responses、其已有别名及 HTTP compact 中用户/工具发来的结构化内联附图。外链、文件 ID、文本、加密摘要和其他接口不改。

新 API 在现有已认证模型能力接口上发布可选的 image_processing：v1 表示识别协议、可沿用基本格式，v1/webp 表示全部候选路由已配置无损 WebP。Turbo 按当前有效凭据和模型读取有期限的能力；未知、过期、旧平台或普通第三方上游沿用既有路径。不会为每个请求阻塞等候探测。能力不可证明 WebP 时无损使用 PNG。

缓存只在本机内存保存压缩后二进制，按上游与凭据、源图内容、输入 MIME 和有效编码参数隔离。同一账号跨会话和 New API 节点可复用，重复位置各算一张，缓存不消除图片的重复传输。最多 64 MiB、512 条、15 分钟闲置过期；同键并发只编码一次，只记确定性无收益结论，不缓存错误。图片缓存默认复用，不单设复选框；设置里可看条数与占用、清空。客户端在有界的后台工作者中处理图片，检查编码大小、解码像素、工作量；失败或超预算整轮保留原图，不向平台谎报已处理。启动本机编码并非保证降低首包：见[32 张合成图的独立测量](../verification/2026-11-24-image-compression-sample.md)。

## 单次请求合同

HTTP 使用 X-AI-Cove-Image-Processing；私有 WS 在**这一帧** response.create 的 client_metadata 使用同名小写键，不设置连接级决策。v1/changed/N 表示本轮实际采用了 N 张压缩结果（含缓存命中，1–256），v1/kept 表示检查完毕但全部保留。无图、关闭、未完成不标记。错误、冲突值不作为有效声明。平台消费并剥离标记，只在调用 image-compress 前跳过该插件，其他插件、限流、大小限制和计费不受影响。声明只是来源信息，不授予权限。

HTTP 与 WS 回退使用各自的请求表示，续传从原始输入构造，避免对上一版有损图再编码。不因压缩添加自动重放条件，413 不会触发再次生成。此前讨论的上传文件、签名 URL 及平台缓存拓扑不属于此改动。

## 日志

Turbo 的请求详情记录图片数量、命中、耗时、前后字节、格式、是否缩放及保留原因；细目最多 16 张，其余显示省略数量，不保存图片、凭据或正文。附图二进制、业务 JSON 与网络应用载荷分开计量。能拿到平台请求号时同步显示；私有 WS 的压图回执只在 Turbo 消费，不交给 Codex。

New API 使用记录保留“来自 Turbo”和版本。仅真正使用了压缩结果时用实心闪电变体；在同一提示中追加一行，例如 **zstd压缩 · 附图已压缩 20 张**。只有 zstd 时显示 **zstd压缩**；没有任何压缩证据或旧记录则不追加。极小的包可能只有图片变小而 zstd 没有使用，此时只显示“附图已压缩 N 张”。HTTP 以实际 Content-Encoding、WS 以本轮成功解析的私有帧标志为准。平台详情只显示“图片已由 Turbo 处理压缩，详情请看 Turbo 客户端记录。”；其他插件仍各记各的。

## 验收与发布边界

用同一条私有 WS 验证三种状态交替；检查出站 JSON/HTTP 头中无私有标记，平台日志不串轮。验证普通 HTTP、关闭总开关、缓存命中、设置保存、账号隔离、整轮失败回退、取消和既有 Hybrid 安全回退。桌面和窄屏使用相同提示，键盘可操作齿轮和提示。优先升级所有接流量的 New API 再灰度发 Turbo；回滚先停止客户端使用这个协议，保留服务端兼容窗口。真实弱设备、限速网络和生产首包 P95 须在灰度阶段单独测量。
